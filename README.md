# Дедупликация кредитных субъектов (entity resolution / record linkage)

Курсовой проект: пайплайн поиска и объединения дублей среди записей о субъектах кредитных историй
на синтетических данных (до 1 млн строк). Подход применим к контролю качества справочников, реестров и внутренних данных.

## Что внутри
- **Генерация синтетических данных** (версия 1 и версия 2 с колонкой `id_loan`): ФИО разного происхождения,
  опечатки (расстояние Левенштейна 1–2, соседние клавиши), транслит, перепутанные части ФИО, ошибки в дате рождения,
  мусорные значения, слитные/раздельные серия и номер паспорта, смена фамилии, коллизии идентификаторов.
- **Baseline на PySpark:** нормализация ключей → блокировка и генерация пар → граф совпадений →
  connected components (итеративное распространение минимальной метки).
- **Оценка качества:** pairwise precision / recall / F1 по истинному `id_sub`.

## Результат baseline
| Метрика | Значение |
|---|---|
| Precision | 0.957 |
| Recall | 0.809 |
| F1 | 0.877 |

Граф: 1 000 000 вершин, ≈ 1.42 млн рёбер.

## Направления улучшений
Fuzzy matching, weighted graph, probabilistic record linkage (Fellegi–Sunter), ML-классификация пар,
использование `id_loan`, проверка сходимости connected components. Подробнее: последний раздел ноутбука.

## Запуск

